# CHIPCAT — GitHub Pages Setup

1. Create a **public** GitHub repository named `chipcat`.
2. Upload the contents of this ZIP to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment → Source**, select **GitHub Actions**.
5. Open **Actions** and wait for **Deploy CHIPCAT to GitHub Pages** to finish.
6. Your site will be:
   `https://YOUR-GITHUB-USERNAME.github.io/chipcat/`

This project is configured for a repository named `chipcat`. If you use another repository name, change `base` in `vite.config.js` to `/YOUR-REPOSITORY-NAME/`.
