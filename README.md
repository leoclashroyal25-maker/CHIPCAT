# CHIPCAT

A polished, non-transactional fictional character/brand showcase built with React + Vite + Framer Motion.

## GitHub Pages

This project is preconfigured for GitHub Pages with a GitHub Actions deployment workflow.

See `GITHUB-PAGES-SETUP.md` for the upload and Pages steps.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site contains no wallet connection, purchase flow, contract address, price/market data, or trading links.
